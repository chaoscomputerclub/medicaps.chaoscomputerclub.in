# Medi-Caps University Chapter — Chaos Computer Club

> **`medicaps.chaoscomputerclub.in`**  
> The official member portal for the Medi-Caps University Chapter of Chaos Computer Club India.

---

## 🏛️ Features

- **Authentication**: Six-digit OTP campus authentication for sign-in, registration, and recovery.
- **Member Dashboard (`/portal`)**: Live activity feed, registered upcoming events, active problems, and member statistics.
- **Problem Archive (`/portal/problems`)**: Searchable algorithmic problem database with custom in-browser CodeEditor and submission queue.
- **Offline Contests (`/portal/contests`)**: University contest schedule, problem sets, and live scoreboard.
- **Campus Events (`/portal/events`)**: Technical workshops, hackathons, and RSVP management.
- **Leaderboard (`/portal/leaderboard`)**: Campus chapter ranking and scoring metrics.
- **Member Profile (`/portal/profile`)**: Identity, skill matrix, and achievement showcase.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Development

```bash
# Install dependencies
npm install

# Start local development server on port 8081
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```
