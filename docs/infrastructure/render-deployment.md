# Render Deployment & P2P Compute Peer Guide

This guide describes how to deploy the CCC Medi-Caps backend as a **P2P Compute Peer** on **Render** (free tier).

---

## 1. Architecture: How Render Fits into the P2P Fabric

```text
Browser ──> Cloudflare Edge ──> Cloudflare Worker (Edge Ingress)
                                      │
                                      ▼
                           ROUTER_PEERS Pool
                                      │
                        ┌─────────────┴─────────────┐
                        ▼                           ▼
            Render Compute Peer            Any Future Provider
     (https://<app>.onrender.com)        (Koyeb / Railway / VPS)
```

- **Stateless Compute**: The Render instance runs the universal [`Dockerfile`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/Dockerfile) in `SERVICE_MODE=all` (API + Outbox Relay + SSE Realtime).
- **Shared State**: The instance connects directly to your authoritative PostgreSQL (Supabase / Managed PG) and Redis (Upstash / Redis).
- **Auto-Registration**: On boot, the [`PeerAgent`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/backend/app/engine/peer_fabric/agent.py) automatically registers `peer-render-01` in the shared Redis registry and starts emitting heartbeats.
- **Cold-Start Resilience**: Render free services spin down after 15 minutes of inactivity. The Cloudflare Worker has adaptive 50s timeouts to absorb cold starts and fails over seamlessly if multiple peers are active.

## 2. One-Click Blueprint Setup on Render

1. Log in to [dashboard.render.com](https://dashboard.render.com/).
2. Click **New +** $\rightarrow$ **Blueprint**.
3. Select the repository `chaoscomputerclub/medicaps.chaoscomputerclub.in`.
4. Render will detect [`render.yaml`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/render.yaml).
5. Fill in the required environment variables:
   - `DATABASE_URL`: `postgresql+asyncpg://<user>:<password>@<supabase-host>:5432/<db_name>`
   - `REDIS_URL`: `redis://default:<password>@<upstash-host>:6379`
   - `SECRET_KEY`: Any 32-character random string (e.g. generated by Render)
6. Click **Apply**.

## 3. Alternative: Manual Web Service Setup on Render

If not using Blueprints:
1. Click **New +** $\rightarrow$ **Web Service**.
2. Select repository: `chaoscomputerclub/medicaps.chaoscomputerclub.in`.
3. **Environment**: `Docker`
4. **Dockerfile Path**: `./Dockerfile`
5. **Region**: `Singapore` (or `Frankfurt` / `Oregon`)
6. **Instance Type**: `Free`
7. Under **Environment Variables**, add:
   - `SERVICE_MODE`: `all`
   - `ENVIRONMENT`: `production`
   - `DATABASE_URL`: your PostgreSQL connection string
   - `REDIS_URL`: your Redis connection string
   - `SECRET_KEY`: your secret key
   - `FRONTEND_URL`: `https://medicaps.chaoscomputerclub.in`
8. Click **Deploy Web Service**.

## 4. Connecting Your Render URL to the Edge Fabric

Once deployed, Render gives you a URL (e.g. `https://ccc-medicaps-api.onrender.com`).

Set it in [`infra/cloudflare/wrangler.toml`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/infra/cloudflare/wrangler.toml):
```toml
[vars]
FRONTEND_ORIGIN = "https://medicaps.chaoscomputerclub.in"
ROUTER_PEERS = "https://<your-service-name>.onrender.com"
```

And re-deploy the edge router:
```bash
cd infra/cloudflare && npx wrangler deploy
```

You can configure multiple comma-separated peers for automatic failover:
```toml
ROUTER_PEERS = "https://<render-app>.onrender.com,https://<koyeb-app>.koyeb.app,https://<railway-app>.up.railway.app"
```
