# Global Platform Transformation Pack

Use `prompts/MASTER_IMPLEMENTATION_PROMPT.md` as the primary coding-agent instruction. Supporting documents define the target architecture, safe legacy migration, and release acceptance. The project must be audited before implementation; this pack does not claim the repository has already been inspected.

Core principle: globally accessible and institution-neutral by default. Organizations are optional workspaces, not identity prerequisites. Historical university data is preserved, not blindly deleted.
