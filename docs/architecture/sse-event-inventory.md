## 1. Executive Summary

This inventory documents all real-time events discovered in the production codebase. The platform utilizes a dual-tier SSE delivery architecture:
1. **Unified Global SSE Stream (`/api/events/stream`)**: Serves public platform lifecycle events, registration counters, timer shifts, global status transitions, and rating updates.
2. **Contest-Scoped SSE Stream (`/api/events/contest/{slug}/stream`)**: Dedicated stream strictly isolating per-submission evaluations and node completion verdicts to prevent cross-contest cache invalidation storms.

The backend streaming pipeline is implemented via:
- Wire Protocol: Standard W3C SSE (`id:`, `event:`, `data:`, `: heartbeat`) in [`backend/app/modules/events/events_service.py`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/backend/app/modules/events/events_service.py).
- Pub/Sub Relay: Redis channel `ccc:realtime:events` with instance UUID loopback suppression in [`backend/app/services/event_broadcaster.py`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/backend/app/services/event_broadcaster.py).
- Replay Buffer: Redis Circular Sorted Set (`ccc:sse:replay:{channel}`) scored by monotonic version numbers for `Last-Event-ID` recovery.
- Backpressure Guard: Per-client bounded in-memory queues (`maxsize=100`); buffer overflow drops the oldest frame and injects `resync_required`.

## 3. Wire Protocol Serialization Format

Every event emitted from [`backend/app/modules/events/events_service.py`](file:///Users/santushtkotai/Desktop/medicaps.chaoscomputerclub.in/backend/app/modules/events/events_service.py) conforms to the standard W3C Server-Sent Events format:

```text
id: 142
event: contest_status_changed
data: {"id": 142, "event": "contest_status_changed", "version": 142, "contest_slug": "code-rush-3", "data": {"old_status": "upcoming", "new_status": "live"}}

```

If an event payload has no explicit version or ID, it is emitted with `data:` and optionally `event:`:
```text
event: pass_checked_in
data: {"event": "pass_checked_in", "timestamp": "2026-10-06T08:30:00Z", "contest_slug": "weekly-1", "data": {"handle": "cadet_42", "seat_number": "A-12"}}

```

Lightweight proxy keepalive heartbeats are emitted every 15 seconds:
```text
: heartbeat

```
