# Glossary

- **Barge-in:** User begins speaking while assistant output is active.
- **Dialogue state:** Operational state of the current conversation.
- **Endpointing:** Estimating that the user has completed an utterance.
- **Expression plan:** Normalized instructions describing intended speech delivery.
- **Full-duplex:** Input and output audio can be active concurrently.
- **Persona:** Stable application-defined behavioural and voice configuration.
- **Prosody:** Rhythm, pitch movement, pauses, stress, and emphasis in speech.
- **STT/ASR:** Speech-to-text / automatic speech recognition.
- **TTS:** Text-to-speech.
- **TTFA:** Time to first audio.
- **VAD:** Voice activity detection.
- **Working memory:** Short-lived context for an active session.
- **Long-term memory:** Durable user context retained across sessions under policy and consent.
- **Provider capability:** A feature explicitly supported by a selected model or service.
- **Cancellation token:** Shared signal used to stop work associated with a response.
