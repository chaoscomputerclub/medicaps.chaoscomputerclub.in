# 10 — Security, Privacy, and Governance

- Candidate can access only their own sessions, responses, reports, and resume context.
- Admin authoring/publishing requires explicit server-side role authorization.
- Generated artifacts are untrusted drafts until validated and approved.
- Internal inference endpoints require service authentication.
- No API keys in frontend bundles, browser storage, source control, logs, or plaintext database fields.
- Track source owner, license, collection date, allowed use, transformation, and approval for reference material and datasets.
- Do not ingest copyrighted/private material without permission.
- Candidate answers are private production data and excluded from training by default.
- Define retention/deletion and redact diagnostics.
- Score job-relevant demonstrated competency, not demographic proxies or accent.
- Accept alternative valid answers and allow uncertainty/clarification.
- Audit artifact creation, generation, review, approval, publication, and model versions.
